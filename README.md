# Prototipo de Mesa de Partes Digital

Proyecto académico del curso Fundamentos de Programación (CIIN1205P).

## Requisitos
- Python 3.9 o superior.
- No requiere bibliotecas externas.

## Ejecución
```bash
python main.py
```

Los expedientes se guardan automáticamente en `expedientes.json` en la misma carpeta.
El archivo JSON se crea al registrar el primer expediente.

## Funcionalidades
1. Registro y validación de datos.
2. Generación de código correlativo.
3. Búsqueda por código.
4. Ordenamiento alfabético por solicitante.
5. Listado y persistencia de registros.
